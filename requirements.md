# Requirements Management

## Functional Requirements
1. The system shall accept student marks.
2. The system shall calculate total marks.
3. The system shall calculate percentage.
4. The system shall assign a grade.
5. The system shall validate user input.

## Non-Functional Requirements
1. The system should be easy to use.
2. The system should provide accurate results.
3. The system should respond quickly.
4. The system should handle invalid input safely.

## Requirements Traceability
| Requirement | Implementation | Test |
|---|---|---|
| Accept marks | Input validation | Input test |
| Calculate total | Total calculation | Total test |
| Calculate percentage | Percentage calculation | Percentage test |
| Assign grade | Grade function | Grade test |
| Validate input | Validation logic | Invalid input test |
